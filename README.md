# ActionDistill 实验代码

从教师轨迹训练工具选择建议器 Jev，执行器负责参数、工具执行和最终回答。

| 主入口 | 用途 |
|---|---|
| [迁移与运行](migration/README.md) | 旧机交付、新机安装，以及基线测评、Jev训练、Ours联合测评三条命令链 |
| [数据审查](dataset_tool_inventory/README.md) | 教师轨迹解析、候选恢复和质量审查 |
| [训练](jev_train/README.md) | 样本构造、训练、离线评测、校准和服务 |
| [标准测评](jev_bench/README.md) | 六项原生 benchmark、基线、评分、恢复和统计 |

将本仓库克隆到 `ActionDistill/experiments/`，依照迁移说明恢复旁边的 `third_party/`。公开代码只维护上述四个项目；第三方源码按固定版本恢复，不复制进本仓库。数据、模型和实验输出不提交 Git，本机历史输出继续保留。

## 文档约定

各子项目只维护三份说明：`PROJECT.md`记录目标、主要资产和稳定约定，`README.md`记录操作入口和精确使用协议，`PROJECT_STATE.md`记录当前阶段、关键结论和待办。跨服务器交付及运行命令统一见[迁移与运行](migration/README.md)。上游README、模型卡、数据包说明和正式实验报告仍随对应资产保存。

## 历史源码复现

公开主线从干净的初始提交开始，只包含当前四个项目及必要根文件。旧开发分支 `archive/pre-mainline`、`jev-dataset-review` 和完整开发历史仅保留在原机本地，不随公开仓库发布；后续开发与推送沿主线继续。

现行文档保留必要的科研定义、结论和未解决问题。旧命令、退役源码和完整历史文档可在原机本地归档中查阅，公开克隆不包含那些提交。数据包中的原构造提交仍保留其原始身份，不因公开提交变化而改写。

原运行的 `metadata/command.txt`、配置、状态和正式结果仍是批次事实来源。历史输出保持原位，复现实验使用新输出，不覆盖已有结果。
